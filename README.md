🏧 ATM Management System
📌 Project Overview

The ATM Management System is a Java-based application that simulates the working of an Automated Teller Machine (ATM).
It allows users to perform basic banking operations like login, balance inquiry, deposit, withdrawal, and mini statement in a secure and simple way.

This project is developed for learning Core Java, Swing GUI, and JDBC database connectivity.

🎯 Objectives

To understand real-life ATM operations

To learn Java Swing for GUI

To implement JDBC for database connectivity

To apply CRUD operations using SQL

To build a mini real-world banking project

🛠️ Technologies Used

Programming Language: Java (Core Java)

GUI: Java Swing

Database: MySQL

Connectivity: JDBC

IDE: Eclipse / IntelliJ / VS Code

OS: Windows / Linux

⚙️ Features

User Login using ATM Card Number & PIN

Balance Inquiry

Cash Deposit

Cash Withdrawal

Mini Statement

PIN Change

Secure Logout

Database-based account storage

🧑‍💻 System Modules

Login Module

🗄️ Database Details

Database Name: atm_db

Table: accounts

Fields:

account_no

name

pin

balance

🚀 How to Run the Project

Install JDK 8 or above

Install MySQL

Create the database and tables

Add MySQL JDBC Driver (mysql-connector.jar) to the project

Open the project in IDE

Compile and run the main file
